# Deus Ex Setup 2026

An automated installer designed to simplify setting up Deus Ex GOTY.

Features:
- Kentie's Launcher
- DeusEx.exe fixes
- DeusEx.u updates
- Map fixes
- Direct3D 10 / DirectX 11 renderer installation
- Optional controller support
- Automatic backups
- DeusEx.ini configuration
- Portable single-file executable

Requirements:
- Deus Ex GOTY (Steam version recommended)
- Windows x64

Run as administrator to allow installation inside Steam folders.
